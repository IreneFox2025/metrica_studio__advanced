# ✦ Metrica (advanced version)

Responsive landing page for an interior design studio. The project focuses on responsive layouts, interactive UI components, and clean website structure.

[![VIEW LIVE DEMO →](https://img.shields.io/badge/VIEW_LIVE_DEMO-%E2%86%92-ad1818?style=for-the-badge&labelColor=ad1818&color=ad1818)](https://irenefox2025.github.io/metrica_studio__advanced/)

## ✦ Features
- ◆ Smooth navigation between page sections
- ◆ Responsive layout for desktop, tablet, and mobile screens
- ◆ Interactive navigation with a mobile burger menu
- ◆ Image carousel powered by Swiper
- ◆ Modal dialog for service inquiries
- ◆ Interactive UI implemented with vanilla JavaScript
- ◆ Native HTML form validation
- ◆ Modal dialog for service inquiries
